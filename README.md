# 집의 흐름 — 아파트 벤치마크

모바일·데스크톱에서 아파트 기간 상승률, 지역 BM 대비 차이, 당시 기준금리를 비교하는 의존성 없는 정적 웹앱입니다.

## 현재 상태

화면과 계산 엔진, CSV/JSON 가져오기, GitHub Pages workflow를 구현했습니다. 번들 데이터는 **모두 가상 예시**입니다. 실제 단지 추천이나 실측 결과로 사용할 수 없습니다. 실제 데이터 수집·동기화와 공개 URL 배포는 아직 완료하지 않았습니다.

## 실행

```sh
python3 -m http.server 8000 --directory site
node tests/engine.test.cjs
```

http://localhost:8000 을 엽니다. HTML 파일을 직접 열면 JSON fetch가 제한될 수 있습니다.

## GitHub Pages

1. GitHub에 `apartment-benchmark` 저장소를 만들고 이 폴더 내용을 main 브랜치에 업로드합니다. `.github/workflows/pages.yml`을 포함해야 합니다.
2. Settings → Pages → Source를 **GitHub Actions**로 선택합니다.
3. Actions에서 Publish apartment benchmark를 실행하고 성공한 deployment URL을 확인합니다.
4. URL은 일반적으로 `https://<사용자>.github.io/apartment-benchmark/`입니다. 실제 배포 성공 전에는 이 주소의 존재를 보장하지 않습니다.

기존 개인 홈페이지나 게임 저장소는 변경하지 않습니다. 빌드·서버 없이 `site` 디렉터리만 게시합니다. API 키를 브라우저 코드나 공개 저장소에 넣지 않습니다.

## 계산 결정

- 단위: 단지 id × 정확한 전용면적. 84㎡와 84.9㎡를 임의로 합치지 않습니다.
- 비교 시점: 지정한 기준일과 1·3·5년 전 같은 날짜. 월말 기준일을 권장합니다.
- 대표가격: 시점 직전 3개월 거래 중간값, 각 창 최소 3건.
- 부족하면 양쪽 창을 모두 6개월로 넓힙니다. 그래도 부족하면 수익률을 null로 둡니다.
- 시작 경계 제외, 끝 경계 포함. 취소 거래 제외. 거래 건수는 계약 건수이며 독립 주택 수가 아닙니다.
- 상승률 = 최근 대표가격 / 과거 대표가격 − 1. 연평균 = 비율^(1/연수) − 1.
- BM: 동일 지역·동일 월의 지수끼리 비교. 값이 없으면 초과성과를 표시하지 않습니다. 지수 종류를 혼합하지 않고 동일 시계열을 사용해야 합니다.
- 층·향·동 보정 없음. 작은 초과성과는 거래 구성 차이일 수 있습니다.
- 기준금리: 정책 변경 효력일부터 다음 변경일까지 유지. 가격과 같은 기간에 별도 그래프로 표시합니다.
- 초기 3건/3개월/6개월은 운영 기본값이지 통계적으로 검증된 신뢰도 기준이 아닙니다.

## 실제 데이터

화면에서 CSV 3개 또는 통합 JSON을 가져올 수 있습니다. 업로드 데이터는 서버에 전송하지 않고 현재 브라우저 메모리에서만 처리하며 새로고침하면 사라집니다. 배포 기본값으로 유지하려면 아래 스크립트로 site/data.json을 교체합니다.

```sh
python3 scripts/build_data.py --transactions 거래.csv --benchmark bm.csv --rates 금리.csv --as-of 2026-09-30 --source '국토교통부 / 한국부동산원 / 한국은행'
```

CSV 열:

- 거래: `id,name,region,area,date,price,floor,cancelled` 가격 **억원**, 전용면적 ㎡, 날짜 YYYY-MM-DD, 취소 true/1/Y.
- BM: `region,month,value` 월 YYYY-MM, 양수 지수. 단지 region과 일치해야 합니다.
- 금리: `date,value` 효력일 YYYY-MM-DD, 연 %. 비교 시작 이전의 유효 금리도 포함합니다.

공식 원천의 만원 가격은 10,000으로 나눠 억원으로 변환해야 합니다. 원천 단지 이름만으로 식별하지 말고 주소·단지 식별자를 사용합니다. 취소·정정·중복 반영, 지역 코드 매핑은 수집 단계에서 처리해야 합니다.

## 남은 연결 작업

- 국토교통부 실거래가: https://www.data.go.kr/data/15126469/openapi.do — 활용신청과 인증키, 월·법정동별 수집.
- 한국부동산원 BM: https://www.reb.or.kr/r-one/portal/openapi/openApiDevPage.do — 인증키 발급 및 정확한 통계표/지역 항목 선정. 실거래지수 공표 지역·주기가 제한되므로 지원되는 지역부터 시작.
- 한국은행 기준금리: https://ecos.bok.or.kr — 효력일 기준 시계열 확보.
- 원천 제공 조건·재배포 조건 검토 후 실제 데이터를 site/data.json으로 생성.
- 각 source의 공통 최신 월을 기준일로 사용. 신고 지연·정정 때문에 최근 월은 재수집 필요.

자동 수집이 완성되기 전 임의의 웹 가격을 섞거나 시장 지수로 개별 단지 가격을 추정하지 않습니다.
